# Roadmap

This roadmap records intended milestones, not delivery dates.

| Milestone | Deliverable | Exit criteria | State |
| --- | --- | --- | --- |
| M0 | Reviewable blueprint | Documents, contracts and structural validation prepared | Prepared |
| M1 | Runnable foundation | React/FastAPI bootstrap, migration and workspace identity verified | In progress — source implemented; Docker/frontend lock/CI evidence pending |
| M2 | Low-code vertical slice | Editor → publish → durable run → approval → mock action; restart and permission tests | Planned |
| M3 | HR validation pack | Job criteria, application intake, evidence and review queue | Planned |
| M4 | Authorized external actions | Provider connection, approved email, form and capacity-safe booking | Planned |
| M5 | Beta | Product acceptance criteria and operational checks pass | Planned |

After beta: advanced subworkflows, branching/joins with explicit semantics, personal automation templates, additional business packs and governance. Do not expand unsupported connectors merely to fill a catalog.

For M1 implementation evidence and remaining gates, read [M1 foundation](09_M1_FOUNDATION.md). For dependencies and phase-level details, read [Implementation plan](07_IMPLEMENTATION_PLAN.md).
